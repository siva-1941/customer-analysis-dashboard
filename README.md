# 📊 Customer Insights & RFM Segmentation Dashboard | Power BI

## 📌 Project Overview
This Power BI project focuses on analyzing customer behavior, purchasing patterns, profitability, and customer segmentation using RFM (Recency, Frequency, Monetary) analysis.

The dashboard provides interactive business insights to help identify high-value customers, improve retention strategies, optimize marketing campaigns, and support data-driven decision-making.

---

# 🎯 Project Objective

To analyze customer data and uncover insights related to customer segmentation, purchasing behavior, profitability, and customer engagement in order to improve business performance and strategic decision-making.

---

# 🛠️ Tools & Technologies Used

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel / CSV
- MySQL
- Data Cleaning & Transformation
- Data Visualization

# 📈 Key Business Insights

- Identified high-value customers using RFM segmentation
- Analyzed customer purchasing behavior and buying trends
- Identified profitable customer segments contributing to revenue
- Detected inactive and low-frequency customers
- Analyzed customer distribution across regions
- Observed customer growth trends over time

---

# 💡 Business Recommendations

- Focus on retaining high-value customers through loyalty programs
- Launch targeted campaigns for inactive and low-frequency customers
- Improve engagement strategies for at-risk customer segments
- Expand marketing efforts in high-performing regions
- Use RFM segmentation for personalized customer marketing strategies

# 🔍 RFM Segmentation Overview

| Metric | Description |
|---|---|
| Recency | How recently a customer made a purchase |
| Frequency | How often the customer purchases |
| Monetary | How much revenue the customer generates |
